# 🎄 Mestre da Ceia & Churrasco (Seu Fim de Ano sem Aperto!)

Landing Page de Alta Conversão e Web App do ecossistema **Mestre da Ceia & Churrasco**.

## 🚀 Estrutura de Arquivos

- `index.html`: **Página de Vendas Principal (Landing Page)** com copy de alta conversão, prova social, seções de dor, Order Bumps e FAQ.
- `app.html`: **Web App Interativo** simulador das 9 telas do ecossistema (calculadora dinâmica, roleta de amigo secreto, cronograma anti-caos, drinks e vitrine com cadeados).
- `boards/`: Telas de apresentação de portfólio em formato 16:9 Ultra HD.
- `images/`: Mockups e boards em alta resolução (Retina / 4K) renderizados para anúncios e página de vendas.
- `render_all.js`: Script de automação para renderizar os mockups em PNG com Edge/Puppeteer.

## 🌐 Como Hospedar na Vercel

### Opção 1: Arrastando a Pasta (Deploy Direto sem Git)
1. Acesse [vercel.com](https://vercel.com) e faça login.
2. Na tela de **Add New...** clique em **Project**.
3. Arraste a pasta `NATAL` para a área indicada de upload de arquivos estáticos.
4. O deploy será gerado instantaneamente com URL pronta (`.vercel.app`).

### Opção 2: Pelo Repositório do GitHub
1. Conecte o repositório `mestre-da-ceia-churrasco` na Vercel.
2. Selecione como projeto estático e clique em **Deploy**.
